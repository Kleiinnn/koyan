# Vue 作业：知行日课

本仓库包含“知行日课”Vue 3 前端和 Express 后端源码。实验报告保存在本地，不在公开仓库中。

- [网站源码](网站源码)
- [原静态版网站](https://zhixing-study-2026.choicehake13.chatgpt.site)

本地运行：进入 `网站源码` 目录，执行 `npm install` 和 `npm run dev`，打开 `http://127.0.0.1:5173`。完整说明见[项目说明](网站源码/README.md)。

原静态版网站未部署 Express 后端；前后端完整版本需在本机运行，或另行部署到支持 Node.js 的平台。
