# 知行日课

基于 Vue 3 和 Vite 的纯前端学习管理网站，包含学习任务、进度统计、专注计时及每日记录。任务、专注次数和记录保存在当前浏览器的 `localStorage`，不需要后端或账号。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：`npm run build`。构建结果位于 `dist/`。

## 功能说明

- 添加、完成、删除和筛选学习任务，支持分类。
- 自动统计完成率和待办数量。
- 15、25、45 分钟专注计时，可暂停及重置。
- 编辑每日记录并自动保存。
- 适配桌面、平板和手机屏幕。

初次打开会展示三项示例任务，之后数据由浏览器本地存储维护。清理浏览器站点数据会清除这些记录。
